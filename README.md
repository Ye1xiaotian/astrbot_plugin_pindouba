# 拼豆吧 🧸

> 嗨，我是**拼豆吧**——住在 AstrBot 里的一座小手工坊。
> 你丢给我一张图片，我就把它钉在深色底板上：一颗豆、一种颜色，一格一格，
> 连背景也不落下，拼出一整幅属于你的拼豆画。

## 我的手艺

```
        ● ● ● ● ● ● ● ●
      ● ● ● ● ● ● ● ● ●
    ● ● ● ● ● ● ● ● ● ● ●
   ……每一颗豆的颜色，都老老实实取自原图
```

- **整图还原**：我的豆子铺满整张图，背景也是画面的一部分，一格都不偷懒
- **颜色忠诚**：每颗豆取原图对应区域的平均色，不添油加醋
- **56 色手工色板**（可选）：想要更"手作"的扁平质感，我可以换上经典拼豆色卡
- **多种拼法**：拼豆（默认）之外，还会盲文点阵、灰阶像素、边缘描线三种老手艺
- **模型朋友**：多模态模型在时，我会自动裁掉背景、拼完还会告诉你"我拼的是什么"；
  它不在或罢工了？我一个人也照拼不误
- **勤俭持家**：同一张图再来一次我直接秒回；30 秒冷却防止你拼豆上头

## 怎么找我玩

我的唤醒暗号是 **`/拼豆`**（不受机器人唤醒前缀影响，私聊群聊都一样）：

```
/拼豆 + 图片                    命令和图片塞在同一条消息里发给我
引用某张图片 + 回复 /拼豆        长按图片引用我就能看见它
先发图片 → 10 分钟内发 /拼豆     手速慢也没关系，我记得你刚发过什么
```

- 一次发了好几张图？我只拼第一张，并老实告诉你
- 同一张图第二次来？直接秒回上次的成品
- 30 秒内催我太多次，我会提醒你冷却（也可以在配置里关掉提醒）

## 我的工具箱（配置项）

| 配置 | 默认 | 说明 |
|------|------|------|
| `provider_id` | 空 | 我的模型朋友 ID；留空就找当前会话默认模型聊 |
| `render_mode` | auto | auto/bead（拼豆，推荐）/ braille（盲文点阵）/ shading（灰阶像素）/ line（边缘描线） |
| `char_width` | 80 | 拼豆画宽度（豆子列数），16–120；越少越粗犷，越多越细腻 |
| `auto_crop` | false | 打开后按模型说的主体框裁掉背景，只拼主体 |
| `bead_palette` | false | 打开后换上 56 色经典拼豆色卡，手工感更强，但颜色会偏离原图一点点 |
| `color` | true | 彩色豆子；关掉就是单色 |
| `send_mode` | image | image（渲染成图片发送，推荐）/ text（发纯字符文本） |
| `call_timeout_seconds` | 90 | 模型朋友思考太久就先放弃 |
| `allow_at_trigger` | false | 打开后 @我 + 图片也可以召唤我 |
| `cooldown_seconds` | 30 | 同一会话的冷却时间 |
| `cooldown_notice` | true | 冷却时要不要吱一声 |
| `enable_cache` | true | 同图缓存识别结果 |
| `cache_ttl_minutes` | 360 | 缓存保质期 |

## 关于我的隐私习惯

如果你给我配了模型朋友，你发的图片会被送去**你自己配置的云端模型**那里让它看一眼。
不配置的话，图片哪儿也不去，只在你自己机器上变成拼豆。

## 想亲手拼一颗？（开发）

```
放进 data/plugins/ 重载即可
python tests/test_plugin_logic.py   # 我的行为规范（无需 astrbot 环境）
python tests/test_renderer.py       # 我的豆子手艺（需要 Pillow）
```

渲染器就一个文件 `renderer.py`：想加新拼法、改豆子形状、调色板，都从它下手。
